kubectl-guard-holmes installed.

HolmesGPT is now running with kubectl-guard PATH-shadowing its kubectl:
  - Secret reads are BLOCKED everywhere ("do not read secrets" default).
  - Production mutations are GATED (agent-relay) for human approval.
  - Every decision is audited to the exporter -> Prometheus.

1. Verify interception from inside the pod:
   kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "kgh.fullname" . }} -c holmes -- \
     env PATH=/opt/shim:$PATH kubectl-guard doctor

     kubectl -n {{ .Release.Namespace }} create secret generic holmes-llm \
       --from-literal=OPENAI_API_KEY=sk-...
   Then: helm upgrade ... --set llm.existingSecret=holmes-llm
